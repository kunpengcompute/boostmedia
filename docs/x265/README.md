# 项目介绍

x265是一款符合高效率视频编码（HEVC/H.265）标准的开源自由软件及函数库。为了提高在Arm架构设备上的视频编码性能，本仓库x265利用了SVE（一种向量化指令集架构）对标准x265进行性能优化。SVE的特点是可以在不同向量长度的硬件上执行相同的指令，这使得x265可以更好地利用Arm架构的向量化运算能力，加速视频编码过程，提高编码质量和效率。

需要注意的是，SVE优化后的x265版本仅适用于支持Arm SVE指令集的设备，如果您的设备不支持SVE，您将无法使用该版本。如果您的设备是x86架构，可以考虑使用标准的x265版本进行视频编码。

## 特性介绍

采用SVE向量化指令对视频编码算子进行深度优化，充分利用鲲鹏平台向量化指令加速，提升视频编码效率。
